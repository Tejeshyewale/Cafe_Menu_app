# ☕ Cafe Menu App

## 📌 Project Overview
This is a **Cafe Menu Application** built using **Python's Tkinter** for the graphical user interface. The app allows users to view a cafe menu, select items, calculate the total bill, and place an order seamlessly.

## 🛠️ Tech Stack
- **Python**: Backend logic and functionality.
- **Tkinter**: GUI for user interaction.

## 🎯 Features
- 📝 **Interactive Menu**: Display of food and beverage items.
- ✅ **Item Selection**: Users can choose multiple items from the menu.
- 💰 **Bill Calculation**: Automatic total price calculation.
- 🛒 **Order Summary**: Displays selected items before confirmation.
- 🎨 **User-Friendly UI**: Simple and easy-to-use graphical interface.
